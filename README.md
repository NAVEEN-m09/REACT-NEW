# JioSaavn UI Clone

A responsive music streaming interface built using **React**, **Vite**, and **Tailwind CSS**.  
This project recreates a JioSaavn-style homepage with a navigation bar, search box, sidebar menu, library section, and trending music cards.

## Features

- JioSaavn-inspired music homepage UI
- Responsive grid layout for trending songs
- Sidebar with Browse and Library sections
- Search bar in the top navigation
- Song/album cards with image, title, and subtitle
- Built with reusable React JSX structure
- Styled using Tailwind CSS utility classes

## Tech Stack

- React
- Vite
- Tailwind CSS
- JavaScript
- HTML/CSS
